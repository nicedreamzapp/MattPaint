# Who else is doing this (researched 2026-11-02, Sonnet agent, web search)

Nothing found that combines all four: model-written 3D scene + physically based render + stroke painting into a paint app + frames into a film. Say "we found nobody else", never "first".

Closest:
- ChetasLua/moss-keeper (github) — "Fable 5.5" anime short in one HTML file; the film is an embedded base64 MP4. No painting process shown.
- Chetaslua posts — reportedly model-written code + Blender + ElevenLabs (not independently reproduced).
- Karpathy Opus 5 LOTR scene (~5,500 lines three.js, ~$10 tokens) — interactive realtime, not a film (secondary sources).
- SceneCraft (ICML 2024, arXiv 2403.01248) — LLM writes Blender Python, vision model critiques; stills only.
- LL3M (UChicago, arXiv 2508.08228) — multi-agent Blender code for single assets.
- BlenderMCP — Claude drives Blender interactively, uses downloaded asset libraries.
- 3D-GPT (arXiv 2310.12945) — LLM sets Infinigen procedural parameters.
- SketchAgent (CVPR 2025) — LLM draws line sketches as stroke commands.
- Paint MCP agents (Gemini driving MS Paint) — simple drawings.
- Paint Transformer (ICCV 2021), Learning to Paint (ICCV 2019) — neural stroke rendering from a given image; closest to our painting step, no LLM/3D.
Cautions: "Fable 5.5" is an unofficial label; don't state it as an official model.
